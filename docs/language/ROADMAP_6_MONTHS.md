# 英语主线：半年能开口交流（V13 路线图）

> 目标不是「学完新概念」，而是 **6 个月后能用英语完成真实交流**（自我介绍、点餐、
> 问路、看医生、打电话、小聊工作）。新概念是**主干**，但它自己撑不起这个目标 ——
> 本文把差距写清楚，再给出可执行的补法。
>
> 现状基线：NCE 主线已有 6 阶段工作台（词/听/读/句/跟/测）、SRS 复习、
> ECDICT 词典（77 万条）、句级 LRC 时间轴。本文档只讲**还差什么**。

---

## 0. 先说实话：新概念能给你什么、给不了什么

| 能力 | NCE 1–4 覆盖情况 | 结论 |
| --- | --- | --- |
| 语法体系（时态、从句、虚拟语气） | 覆盖极好，例句经典 | ✅ 当主干 |
| 分级阅读难度 | 平滑递增，句短 | ✅ 当分级读本 |
| 听力素材（每课音频 + 句级时间轴） | 覆盖好，英音清晰 | ✅ 当听力语料 |
| **现代口语 / 俚语 / 语域差异** | 几乎没有（1960s 书面体） | ❌ 必须补 |
| **高频词块 / 搭配**（`make up one's mind`、`be into`） | 隐含在课文里，没有被教 | ⚠️ 必须**挖出来**并单独学 |
| **输出训练**（复述、角色扮演、写作） | 没有 | ❌ 必须补 |
| **发音反馈** | 只有音频，没有反馈 | ❌ 必须补 |
| **真实交流场景**（点餐/问路/电话/面试） | 没有 | ❌ 必须补 |

**所以路线是：NCE 打语法与输入的地基 + 自建「交流层」补输出、词块、场景、反馈。**
这四件事恰好是现代 App（Duolingo / Anki / Language Reactor / ELSA）做得比教材好的地方 ——
我们抄它们的**做法**，不抄它们的游戏化外壳（排行榜、连胜、付费墙对本机自用没有价值）。

---

## 1. 6 个月要达到什么（可检查的checkpoint，不是感觉）

| 周次 | 真实能力（能做到就算过） | 本 App 负责提供 |
| --- | --- | --- |
| W2 | 自我介绍 60 秒（姓名/职业/家乡/爱好），不看稿 | 课文复述 + 录音自评 + AI 纠错（未配置则自评清单） |
| W4 | 能在餐厅点餐、买单、要求换菜 | 场景任务卡（AI 对话 / 跟读情景句） |
| W6 | 能听懂 NCE 课文 80% 并复述大意 | 精听 + 逐句听写 + 复述 |
| W8 | 问路、乘车、买票不怯场 | 场景任务卡 + 高频句块卡 |
| W12 | 电话/视频里做自我介绍 + 简单问答 | AI 对话陪练（角色：面试 / 客服 / 同事） |
| W16 | 能读懂 800 词新闻并复述 | 时评类扩展阅读（本地导入）+ 生词挖掘 |
| W20 | 能就熟悉话题聊 10 分钟不冷场 | 话题包 + 口语产出任务 |
| W24 | 能写 200 词邮件/留言并自查 | 写作任务 + 反馈回路 |
| W26 | **模拟真实场景 30 分钟对话，全程英文** | 综合模拟 + 复盘清单 |

「能不能交流」不看课时数，看**可观察的产出**。因此进度页必须显示
「最近 7 天你说了多少分钟、听写正确率、复习留存率、场景任务完成数」，
而不是「已学 42 课」。

## 2. 学习科学基线（从现代 App 抄的四条做法）

| 做法 | 来源思路 | 本项目的落法 |
| --- | --- | --- |
| **主动回忆优先**（不认词，要能造句） | Anki 的 retrieval practice | 「句子挖掘」：把学过的课文句变成填空/听写/中译英卡，进同一 SRS |
| **语境化词汇**（词在句里学） | Language Reactor / Migaku | 复习卡带原句 context；查词浮层显示原句 |
| **可理解输入 i+1** | 精听法 | 听力以 90% 懂为准；提供「逐句重听 + 慢速 + 隐藏文本」三档 |
| **输出必须有反馈** | ELSA / 口语陪练 | 跟读 → 语音识别 → 词级 diff 评分（无识别能力时诚实降级为自评） |

不做的事：不做假分数、不做「发音 92 分」这种编造、不做需要联网才能用的强依赖。

## 3. 六个工作包（每个都是可交付的垂直切片）

### W1 沉浸式精读（Immersive Reader）— 沉浸感的载体 ✅ 已实现
- 全屏无侧栏、逐句时间轴同步高亮（卡拉OK式跟读高亮）
- 点词即查（不跳页）、整句朗读、0.6×–1.5× 变速
- 中文可「一句一现 / 全显示 / 全隐藏」（i+1 输入的关键开关）
- 字号/行距/最大宽度可调；键盘流（空格播放、←/→ 换句、E 英文、C 中文、Esc 退出）
- 会话计时 + 今日目标进度；结束后写回学习秒数与句位

### W2 跟读发音评分（Speaking Loop）— 开口有反馈 ✅ 已实现
- 复用 **已有但从未被调用的** `core::language::speaking::{score, compare_words}`
- 录音 → 浏览器语音识别转写 → Accuracy / Completeness / Fluency + 词级 diff
- 识别不可用（离线/无麦克风）→ 诚实降级：录音对比 + 自评清单，**不编造分数**
- 分数按句写入课程进度，出现在进度页「开口时长 / 平均准确率」

### W3 句子挖掘（Sentence Mining）— 把读过的东西变成复习卡
- 从已学课文的句子自动生成三类卡：**填空（cloze）/ 听写 / 中译英**
- 挖空位置只选**内容词与功能词中的高价值位**（不定冠词、助动词、介词优先 —— 这些是口语高频错点）
- 卡带原句 context，进平台 SRS（`UniversalReviewCard`），复习时先看句再回忆
- 每课学完自动提示「本课可挖 N 句」；用户可一键挖 / 全部挖

### W4 词块与高频句式（Chunks）— 补新概念的短板
- 从 NCE 课文统计 n-gram，筛出**高频动词 + 介词/副词搭配**（`put off`、`depend on`、`give up`）
- 词块作为独立学习单元：整块朗读、整块挖空、整块复习
- 目标量：6 个月累计 300–500 条常用搭配，覆盖「请求/拒绝/建议/原因/时间/价格」六类沟通功能

### W5 场景任务与 AI 对话陪练（Speak Pockets）— 真实交流的最后一公里
- 12 个高频场景（点餐、问路、酒店、购物、看病、打车、电话、机场、办公室闲聊、面试、投诉、社交）
- 每个场景：必说句块 + 追问 + 常见听懂障碍；先跟读，再自由对话
- AI 未配置 → 场景退化为「情景句跟读 + 自评 checklist」，功能不残废

### W6 26 周路线图与能力检查（Roadmap & Milestones）
- 首页把「今日任务」升级为「今日目标 + 本周里程碑 + 距下一个能力检查还有几天」
- 进度页展示真实指标：开口分钟、听写正确率、复习留存率、场景任务数、听力通过率
- 每 4 周一次**能力自测**（听力 5 句 + 复述 + 场景任务），结果入历史曲线

| 工作包 | 落地位置 | 关键设计 |

「朗读评分（识别桩 → HTTP → Rust 打分 → 词级差异 → 统计进账）」全链路。

## 4. 实施顺序（按「用户能感知的价值」排序）

1. **W1 沉浸式精读**（先给感觉：打开就想读下去）
2. **W2 跟读发音评分**（先给反馈：知道自己说得像不像）
3. **W3 句子挖掘**（先给积累：读过的东西留在脑子里）
4. **W6 路线图**（先给方向：知道自己在第几周、离能交流还差什么）
5. **W4 词块**（中期）
6. **W5 场景陪练**（后期，依赖 AI 配置时体验最好，不配置也能用）

每个工作包独立可发布、独立可验证：Rust 纯函数有单测，HTTP 有黑盒用例，
前端有 vitest，关键路径用真实浏览器 + 真实 server 跑一遍。

---

## 5. 数据与诚实边界

- 一切进度数据落 `config/language.db`（课程/进度）与 `config/learning.db`（SRS/复习）；
- 发音评分**只在真的拿到识别结果时给分**，否则显示「无法评分」并说明原因；
- 能力检查的结论来自真实指标，不由「完成课时数」推断；
- AI 相关功能未配置时一律明确说明并降级，不做「假装有人陪你练」。
